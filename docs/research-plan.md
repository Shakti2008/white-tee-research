# Research plan

## 1. Define the comparison set

- [ ] Decide customer segment and initial geography.
- [ ] Validate the candidate queue and find current single-product specialists.
- [ ] Select 10–15 brands across the defined groups, with a reason for each inclusion.

## 2. Complete desk research

- [ ] Create a profile from the template for each selected brand.
- [ ] Capture one exact white T-shirt SKU per brand.
- [ ] Normalize price per tee and record shipping, returns, bundles, and guarantees.
- [ ] Capture fit, fabric, construction, sizing, and traceability evidence.
- [ ] Review brand storytelling, channels, merchandising, and purchase experience.

## 3. Add customer and product evidence

- [ ] Interview buyers about their last white T-shirt purchase and unmet needs.
- [ ] Code customer review themes with source and sample limitations.
- [ ] Select and buy a small comparable sample set after choosing a protocol and budget.
- [ ] Test fit, opacity, shrinkage, collar retention, and wash durability consistently.

## 4. Synthesize

- [ ] Build a sourced comparison matrix.
- [ ] Distinguish observed gaps from untested hypotheses.
- [ ] Prioritize opportunities by customer importance, evidence strength, and feasibility.
- [ ] Write a decision memo before starting brand or product development.

## Hypothesis backlog

These are questions to investigate, not findings: Does opacity drive repeat purchase? Does collar durability justify a premium? Is fit consistency more valuable than fabric storytelling? Does a one-product range reduce choice friction?
